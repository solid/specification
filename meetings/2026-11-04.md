* eP: I already expressed different concern I have. Not very deterministic for the client. The user will know through the client what will apply and what not. CB you had a example ? could we add it to Pivot ?

* eP: if understand, prohibition has priority. What about inheritance ? what if difference between a container access control and a resource ?
* CB: a container in wac doesn't override a ressource access control. as soon as you have a dedicated access control it take over. 
* eP: [something about issue with different client acting on the different access control]] what the experience with WAC only client if policy not set with WAC ? ( with ODRL for example ) is there a warning ? 
* CB: The way to present acess to user is abstacting on the actual policy or rule that is set. for example, or ORDL we describe it but don't give to the user. * eP: true for the client who is just reader, but we are talking here of the client that has control on the access rules. In SolidOS that speak WAC only, if I set ACP policy, SolidOS won't be able to understand it.

* eP: just saying there will be some blind spot
