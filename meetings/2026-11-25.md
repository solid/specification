### New Work Item Proposal: Solid DCAT Profile for Dataset Discovery

URL: https://github.com/solid/specification/issues/830

* CB: It marries/joins DCAT vocab with the capabilities that soild provides. Specifically storage and access control. Joint work of Karlsrhue and Wupp.... univerisities. How data catalog could describe which resources are stored on Solid pods. DCAT is already a W3C spec and widely used. There's DCAT-AP profile required for open data published by EU. We can reuse the same terms. Hosting in on soild storage enables that catalog can be access controlled. With open data you have open read access. In Solid pod you may want to hide some metadata. Even existance you can disclose selectively. It can fill the gap between type indexes, Pavlik argues that they have poor privacy. 
* NdM: In project I work on they also ask to use DCAT (See [DCAT-AP-LU](https://mindig_lu.gitlab.io/DCAT-AP-LU/)). We will probably use it, our app will be open source.
* CB: If you have feedback, please let us know. I've been talking to other implementers using DCAT. We will keep working on it. 
* eP: Excited to see movement in that area. Seems like you did your homework.
... I will try to do a user journey how it could be done with SAI
... will the other authors be involved more in the future
* CB: They are still searching fror a data to make things happen.
* JW: I have a couple of comments and questions, we have a project with use case around supply chain tracking of carbon emssions. We have data products with carbon emissions, and we have markets that need to discvoer the data products of farmers. For that step to discover, they do not know which pods to look in, so we might need to build a centralized catalog of the different datasets.

You can have access control on individual metadata, but in eclipse data space style you can have a query endpoint and get result back as a query. The way we do it helps to think about access control. On the second question, letting sombebody know of new catalog being created and adding it to catalog. I need to ask Florian.
